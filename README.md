# ⚖️ Nyaya AI – Legal Assistant for Everyone

An AI-powered legal assistant designed to simplify complex legal queries into easy, understandable language for everyone. Nyaya AI helps users understand legal concepts, rights, and procedures through an intuitive and user-friendly interface.

## 🌐 Live Demo

👉 https://nyaya-ai-legal.vercel.app

---

## 📌 Features

- 🤖 AI-powered legal query assistance
- 🌍 Multi-language support
- 💬 Interactive chatbot interface
- ⚡ Fast and responsive user experience
- 📱 Mobile-friendly design
- 🎨 Modern and clean UI
- 🔎 Simplifies legal terminology for common users

## 🚀 Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/bhattsana/nyaya-ai-legal.git
```

### Navigate to Project Folder

```bash
cd nyaya-ai-legal
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
